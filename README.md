# 📊 Data Analytics Project – Sentiment Dataset Analysis

## 📌 Project Overview
This project demonstrates a complete **Data Analytics workflow** using Python. The objective was to clean and preprocess a sentiment dataset, perform Exploratory Data Analysis (EDA), and create visualizations to identify trends and patterns.

This project was completed as part of the **Codveda Technologies Data Analytics Internship**.

---

## 🎯 Objectives

- Clean and preprocess the dataset.
- Handle missing values and duplicate records.
- Standardize inconsistent data formats.
- Perform Exploratory Data Analysis (EDA).
- Visualize data using different charts.
- Generate summary statistics and insights.

---

## 🧹 Task 1 – Data Cleaning

The following preprocessing steps were performed:

- Loaded the dataset using Pandas.
- Removed duplicate records.
- Checked and handled missing values.
- Standardized categorical values.
- Converted timestamp values into datetime format.
- Saved the cleaned dataset.

**Output**

- `cleaned_sentiment_dataset.csv`

---

## 📈 Task 2 – Exploratory Data Analysis (EDA)

Performed:

- Dataset overview
- Summary statistics
- Mean
- Median
- Mode
- Standard deviation
- Correlation analysis
- Heatmap
- Histogram
- Box plot
- Scatter plot

---

## 📊 Task 3 – Data Visualization

Created the following visualizations:

- Bar Chart – Sentiment Distribution
- Bar Chart – Platform Distribution
- Line Chart – Average Likes by Month
- Scatter Plot – Likes vs Retweets

All visualizations were exported as PNG images.
